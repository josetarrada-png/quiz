# Quiz de JavaScript

Quiz de preguntas de JavaScript para aprender programación.

## Cómo funciona

Al abrir el quiz aparece una pregunta con cuatro opciones. Al elegir una, se bloquean todas, se muestra "Correcto" o "Incorrecto" con una franja verde o roja, y la opción correcta se destaca mientras las demás se atenúan, aciertes o falles. Pasado un momento, el quiz pasa solo a la siguiente pregunta. Al terminar, muestra los aciertos y un botón para reiniciar, que vuelve a la primera pregunta.

## Tecnologías usadas

HTML, CSS y JavaScript.
